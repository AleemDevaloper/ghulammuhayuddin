# SignalDesk — Project 1 Phase 2 (Professional Interactive CRM)

## Start here
Extract the complete ZIP. Open `02_Interactive_App/SignalDesk.html` in Chrome or Edge, then click **Enter workspace**. The app is a self-contained, offline HTML/CSS/JavaScript prototype; no server installation is necessary. It is *not* a PDF gallery.

## New in Phase 2
- Contacts: filter, search, inspect, create and export.
- Companies: search, segment, create and export account records.
- Tasks & Calendar: create, edit, complete, filter and export tasks, and view a date-based calendar.
- Email Templates: edit, duplicate, delete, preview variable substitution and save drafts.
- Notifications: review, mark read and navigate to related areas.
- Integrations: review connector plans for CRM, automation, mail and API services; save configuration notes without credentials.
- Reports & Exports: calculate source/stage values from current local records and export CSV.
- Audit History: track local task, template, account and preference changes.
- Workspace Settings: name, business hours, timezone, notification preferences and role preview.
- Welcome screen: role preview/sign-in presentation (not real authentication).

Phase 1 screens (Overview, Lead Intelligence, Sales Pipeline, Approval Queue, Workflow Studio and Analytics) remain in the application.

## Important portfolio note
This is an **independent software demonstration**, not a paid client delivery. All data, company names and metrics are fictional. Functional actions run locally in the browser and browser storage, not in a production backend. There are no live email, OpenAI, n8n or third-party CRM connectors, and the welcome/role screen does not provide secure authentication. Represent it accurately on Upwork.
