# DAYLINE — Scope and feature matrix

| Feature | Demonstration | Connected to production? |
|---|---|---|
| Executive overview | 68 synthetic calls + KPIs and charts | No |
| Live reception console | Interactive local routing and intent scenario | No voice/STT/telephony |
| Call inbox and conversation intelligence | Synthetic search, review and transcript | No actual recordings |
| Appointments & dispatch | Local create/edit, basic slot conflicts and calendar | No Google/Microsoft calendar |
| Customer directory | Search and create local customers | No CRM sync |
| Call-flow studio | Simulated route testing and editable blueprint | No external execution |
| Knowledge base | Local policy knowledge management | No live LLM/RAG |
| Review queue | Human review and status workflows | Browser-only |
| Analytics / quality / audit | Demo reporting and CSV exports | No server database |
| Integrations | Setup checklist and example JSON | Not connected |
| Callback Planner — NEW | Assign, mark done/reopen, CSV | No real outbound call |
| Reminder Center — NEW | Draft/clear reminders and CSV | No SMS/email sending |
| Business Hours Rules — NEW | Editable hours and simple sample route test | No live telephony routing |
| Reception Playbooks — NEW | Edit and save five local call scripts | No speech synthesis |
| Settings | Local workspace preferences | No secure authentication |

All records, metrics, and customers are fictional. A demo workflow must not be presented as a deployed AI voice agent.
