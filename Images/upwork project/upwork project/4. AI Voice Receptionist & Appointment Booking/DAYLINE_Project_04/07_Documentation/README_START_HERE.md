# DAYLINE — Voice Reception & Booking Studio

Redesigned from the user-provided `4. AI Voice Receptionist & Appointment Booking.zip` reference demo.

## How to open

1. Extract the complete ZIP to a normal folder.
2. Open `01_Interactive_App/DAYLINE_Voice_Reception_Studio.html` in Chrome/Edge.
3. Use left navigation. All 19 views are within the same HTML file.
4. Data changes are local to your browser only. For a clean demonstration, use a private/incognito window.
5. The sample n8n blueprint is in `06_Workflow_Blueprint` and is **not** deployed. It has no live credentials.

## Important truth in portfolio representation

This is an **independent browser-based portfolio prototype**. The live call console is a deterministic simulation, not a real telephony/LLM/speech service. Calls and messages are **never actually sent**. No customer data is real; there is no hosted API or secured database.

## Upwork title

DAYLINE | AI Voice Receptionist & Appointment Booking Studio

## Upwork description

DAYLINE is a self-initiated voice reception and appointment-booking concept for US service businesses. I designed a browser-based workspace that brings call scenarios, conversation history, local appointment scheduling, customer records and staff follow-ups together. The redesigned interface adds a callback planner, reminder drafts, business-hours rules and editable reception playbooks. The demo uses fictional data and local simulations; it does not place real calls or connect to live voice or messaging APIs.
